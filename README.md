# Lazy Reader

Website and free web app for **Lazy Reader**, the read-aloud app by Prerak's App World.

- `/` – product website
- `/app/` – Lazy Reader for the web (installable, works offline, files stay in the browser)
- `/privacy.html` – privacy policy and terms of service

Source of the web app: `lazy-reader-android/web` (built with Vite; output copied to `app/`).
